# CYBERFORGE

**Cybersecurity Forensics & Hidden Message Analysis**

A Windows desktop tool for learning digital forensics and analysing files for hidden messages, built for education and authorized testing.

## About

CYBERFORGE brings forensic analysis and hidden-message detection into a single application. It is designed for students, beginners and security enthusiasts who want to practise investigation techniques in a safe, hands-on way.

It is packaged as a standalone Windows executable, so it can be run without setting up a Python environment.
